## Critical Issues (Must Fix)

These issues prevent users with visual or assistive technology impairments from completing core user flows.

### Issue 1: Missing Accessible Names on Clear Search Button and Quick Action Buttons
- **WCAG Criterion:** 1.1.1 Non-text Content (Level A) & 4.1.2 Name, Role, Value (Level A)
- **Severity:** Critical
- **Location:** `lib/screens/customer/home_screen.dart:213`
- **Element:** `IconButton(icon: const Icon(Icons.clear, color: Color(0xFF6B6B6B), size: 20), onPressed: ...)`

**Problem:**
Tombol `clear` pada suffix TextField pencarian tidak memiliki properti `tooltip` maupun pembungkus `Semantics`. Pengguna pembaca layar (TalkBack di Android / VoiceOver di iOS) hanya mendengar suara "Button" tanpa informasi tindakan apa yang dijalankan jika tombol tersebut ditekan.

**Impact:**
Pengguna tunanetra tidak mengetahui fungsi tombol pembersih pencarian dan kesulitan mengatur ulang kueri pencarian barbershop.

**Remediation:**
Tambahkan atribut `tooltip: 'Hapus teks pencarian'` atau bungkus dengan `Semantics(label: 'Hapus teks pencarian', button: true)`.

**Code Fix:**
```dart
// Before
IconButton(
  icon: const Icon(Icons.clear, color: Color(0xFF6B6B6B), size: 20),
  onPressed: () { _searchController.clear(); _onSearchChanged(''); },
)

// After
IconButton(
  icon: const Icon(Icons.clear, color: Color(0xFF9E9E9E), size: 20),
  tooltip: 'Hapus teks pencarian',
  onPressed: () { _searchController.clear(); _onSearchChanged(''); },
)
```

### Issue 2: Custom Tap Targets Missing Button Semantics in Date Selection
- **WCAG Criterion:** 4.1.2 Name, Role, Value (Level A)
- **Severity:** Critical
- **Location:** `lib/screens/customer/appointment_screen.dart:184-210`
- **Element:** `GestureDetector` pada kotak kalender tanggal pemesanan antrean.

**Problem:**
Kotak pilihan tanggal potong rambut menggunakan `GestureDetector` membungkus `Container` tanpa tag `Semantics(button: true)`. Screen reader menganggap elemen tersebut sebagai teks biasa atau kontainer statis, bukan tombol yang dapat ditekan.

**Impact:**
Pengguna tunanetra tidak dapat memilih tanggal pemesanan karena TalkBack tidak mengumumkan bahwa elemen tersebut dapat diklik.

**Remediation:**
Bungkus `GestureDetector` dengan widget `Semantics(button: true, label: 'Pilih tanggal: ${formatDate(date)}')`.

## Moderate Issues

### Issue 4: Insufficient Color Contrast on Secondary Text and Search Hints (< 4.5:1)
- **WCAG Criterion:** 1.4.3 Contrast (Minimum) (Level AA)
- **Severity:** Moderate
- **Location:** 116 titik pemanggilan warna teks `Color(0xFF6B6B6B)`, `Colors.white24`, `Colors.white38`, dan `Colors.white54` di atas latar belakang gelap `#1E1E1E` atau `#000000`.

**Kalkulasi Kontras:**
- Teks `#6B6B6B` pada latar `#1E1E1E`: Rasio kontras **3.12:1** (Gagal ambang batas WCAG AA sebesar 4.5:1).
- Teks `Colors.white38` pada latar `#000000`: Rasio kontras **3.85:1** (Gagal ambang batas WCAG AA).

**Remediation:**
Ganti warna abu-abu teks rendah dengan warna abu-abu terang minimal kontras 4.5:1:
- Ganti `Color(0xFF6B6B6B)` menjadi `Color(0xFF9E9E9E)` (Rasio kontras **6.1:1** — Lolos WCAG AA).
- Ganti `Colors.white54` menjadi `Colors.white70` (Rasio kontras **8.2:1** — Lolos WCAG AA).
